Panduan Pasang Aplikasi Baru

1-Klik Siap Pakai
Gunakan huruf kecil, angka, dan tanda minus. Contoh: absensi-kantor atau layanan-antrian.
Akan dapat diakses di: http://server:[otomatis]
2. Sumber Kode Aplikasi
Pilih apakah Autore perlu menyiapkan kode contoh agar aplikasi langsung jalan.
✨ Contoh Siap Pakai (Recommended)
Autore membuatkan web server ringan. Setelah pipeline selesai, web langsung dapat dibuka dan dites di browser.
📁 Kode Sendiri di Folder
Gunakan source code aplikasi yang sudah Anda simpan di folder kerja server.
3. Alokasi Port Server
Pilih port acak otomatis agar tidak bentrok dengan layanan lain di server.
⚡ Otomatis (Direkomendasikan)
Sistem otomatis mendeteksi port bebas (mulai 8003). Dijamin tidak bentrok dengan aplikasi lain.
⚙️ Tentukan Nomor Port
Tentukan nomor port tertentu secara manual (1024 - 65535). Port 8080 & 9000 dilarang.
